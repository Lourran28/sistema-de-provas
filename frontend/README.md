# Front-end

Interface do sistema de geracao e correcao de provas.

Stack:

- React
- TypeScript
- Tailwind CSS
- React Router
- Vite

## Comandos

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

## Ambiente

Crie `.env` a partir de `.env.example` quando precisar alterar a URL da API:

```bash
VITE_API_URL=http://localhost:8080/api
```
